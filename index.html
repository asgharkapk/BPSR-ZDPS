Getting Started

Before ZDPS can capture combat packets and begin displaying real-time combat information, a few required dependencies must be installed. The application is portable and does not require a traditional installer, but **Npcap** and **.NET 9 Desktop Runtime** must be available first.

1. Install Npcap

Required

ZDPS depends on Npcap for packet capture. Without it, combat packets cannot be read and the application will not function correctly.

  • Download latest Npcap release
  • Install version 1.85 or newer
  • Restart the game if already running
  • Verify packet capture works
IMPORTANT Most startup problems are caused by Npcap not being installed.

2. Install .NET 9

Desktop Runtime

ZDPS is built on .NET 9 and requires the Desktop Runtime. Only the Desktop Runtime should be installed. The SDK is not required.

  • x64 Desktop Runtime
  • .NET 9.x
  • Restart application afterwards
  • Automatic prompt if missing
Install the Desktop Runtime, not ASP.NET Runtime and not the SDK.
Installation Process

Download Dependencies

Download the required components before launching the application.

Install Npcap

Allow Windows network packet capture. Restart Blue Protocol afterwards.

Install .NET Desktop Runtime

Required runtime used by ZDPS.

Download ZDPS Release

Download the latest ZIP package. Do not download Source Code archives.

Extract Files

Extract to a normal folder. Avoid Program Files because Windows permissions may interfere.

Launch

Run BPSR-ZDPS.exe There is no installer. ZDPS is completely portable.

VPN Notice

VPN Users

If a VPN is used, connect the VPN before launching ZDPS. The application automatically selects the active network adapter during startup. If the VPN is enabled afterwards, restart ZDPS or manually choose the correct Network Capture Device inside the Settings menu. Changing adapters while running may stop packet detection until the adapter is reselected.
